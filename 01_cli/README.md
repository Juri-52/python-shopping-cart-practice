# 第1段階：CLIでショッピングカートを作る

コンソールのメニューから商品を追加・削除し、カートの中身と合計金額を表示します。今回はファイルの読み込みや画面作成は行いません。

## ファイルと作業順

1. `product.py`：Productを完成させる。
2. `cart.py`：Cartを完成させる。
3. `main.py`：商品オブジェクトの作成とメニューを書く。

配布済みの `catalog.py` には10商品の辞書を入れた `PRODUCTS` があります。main.pyで読み込み、各辞書からProductオブジェクトを作ってリストにまとめてください。商品データは変更しません。

## 1. 商品クラス：Product

### 属性

| 属性 | 内容 |
| --- | --- |
| `product_id` | 商品番号。カタログ内の重複しない整数 |
| `name` | 商品名 |
| `price` | 1点あたりの価格。整数の円価格 |

### メソッド

- `__init__(product_id, name, price)`：受け取った値を属性に保存する。
- `get_info()`：`1. ノート - 200円` の形式の文字列を返す。メソッド内で `print()` はしない。

商品の価格は変更しません。表示用の文字列は、商品一覧とカート一覧の両方で使います。

## 2. カートクラス：Cart

### 属性

`items`：カートに入った **Productオブジェクト** を保存するリスト。最初は空です。名前だけのリストではありません。

同じ商品を2回追加した場合は、同じProductオブジェクトがリスト内に2回入って構いません。商品の番号や価格を変更してはいけません。

### メソッド

| メソッド | 処理と戻り値 |
| --- | --- |
| `__init__()` | 空の `items` を作る |
| `add_product(product)` | 受け取ったProductを1点追加する。戻り値の指定は不要 |
| `remove_product(index)` | 有効なインデックスならその1点を削除して `True`。範囲外なら変更せず `False` |
| `get_total()` | 現在の全商品の `price` を合計した整数を返す。空なら `0` |

`remove_product()` のインデックスは0から始まります。負の値や、リストの長さ以上の値は無効です。**商品番号（product_id）とは別の値です。**

合計金額は何度計算しても同じ値になるようにしてください。計算するだけで商品の単価やカートの中身が変わってはいけません。

## コンソールメニュー

`main.py` に次の操作を用意します。

```text
1: 商品一覧 / 2: 追加 / 3: カート / 4: 削除 / 0: 終了
```

| 選択 | 処理 |
| --- | --- |
| 1 | 配布された10商品の番号・名前・単価を表示する |
| 2 | 商品番号を入力し、対応するProductをCartに1点追加する |
| 3 | カートの行番号・商品名・単価、商品数、合計金額を表示する |
| 4 | カートを表示し、入力された行番号の1点を削除する |
| 0 | 繰り返しを終了する |

追加・削除に成功した後も、現在のカートと合計を表示してください。

起動時にProductのリストとCartを一度だけ作ります。メニューのたびに作り直してはいけません。カートに同じ商品を複数回入れられるようにします。

**商品番号とカートの行番号は別です。** 商品の追加ではproduct_idを探します。削除では、カートの表示行番号を使います。画面には行番号を1から表示し、Cartのメソッドには0から始まるインデックスを渡します。

カートの表示例：

```text
1. ノート - 200円
2. ノート - 200円
3. ボールペン - 150円
商品数: 3点 / 合計: 550円
```

## 入力の確認

- 商品番号や行番号を整数に変換できなければ案内を表示する。
- 存在しない商品番号では追加しない。
- 0以下や範囲外の行番号では削除しない。
- 空のカートではその旨と合計0円を表示する。
- メニューに0〜4以外を入力した場合は案内を表示する。
- 不正な入力でもメニューを続けられるようにする。

## 実行と確認

このフォルダーで `python3 main.py` を実行します。配布された10商品が表示されること、単価から手計算した合計と一致すること、再起動後はカートが空になることを確認してください。同じ商品を2回追加し、1点削除したときの金額も確認します。
