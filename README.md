# 自主課題：ショッピングカートを2段階で作ろう

文房具ショップの商品をカートに追加し、合計金額を計算するアプリケーションを作ります。最初にコンソール版を作り、次にJSONから商品を読み込むように変更します。実際の注文や支払いは行いません。

| 段階 | フォルダー | 新しく作る部分 |
| --- | --- | --- |
| 1. CLI | [01_cli](01_cli/README.md) | Product、Cart、コンソールメニュー |
| 2. CLI + JSON | [02_cli_json](02_cli_json/README.md) | JSONの読み込み |

各段階のREADMEを読み、順番に進めてください。Pythonファイルのひな形には `pass` があります。

## 共通ルール

- 両段階とも配布された同じ10商品を使います。第1段階はcatalog.py、第2段階はproducts.jsonから読み込みます。

- カートはProductオブジェクトのリストを持ちます。商品名だけを保存する方法は使いません。
- カートの選択した1行だけを削除できるようにします。
- 金額は整数の円価格です。単価を変更せずに合計します。
- 税・送料・割引・在庫管理・決済は作りません。
- カタログは変更しません。カートは保存せず、再起動すると空になります。

## 起動するファイル

実行する段階のフォルダーでターミナルを開きます。

- 第1・第2段階：`python3 main.py`

環境によっては `python3` の代わりに `python` を使います。配布直後のひな形ではアプリケーションは動作しません。
